## 💻 Sobre:

Projeto desenvolvido como atividade prática da disciplina de <strong>Linguagem de Programação</strong>, cursada no segundo período de Sistemas de Informação.

O projeto consiste em um sistema de cinema implementado em Python, com funcionalidades de interação com o usuário e interação com arquivos .txt. Foram implementadas funções básicas de um sistema de cinema, como:

- Cadastro de filmes
- Exibição do catálogo
- Venda de ingressos

Este projeto conta com funções fundamentais da linguagem Python, como: manipulação de arquivos, estruturas condicionais, laços de repetição, funções e organização de código.
